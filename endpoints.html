Five route families that matter

The shared contracts below cover nearly every public route discovered during the investigation.

Content collections

/pages/{collection} returns HTML through DatatableBrowseWidget. Use response links; do not construct slugs.

Detail records

/pages/{collection}/{slug}-{shortid}-{objectid} returns a ContentViewerWidget, metadata, body, and attachments.

File viewers

/pages/files/{objectid} returns an HTML viewer containing direct Oracle Object Storage URLs.

AJAX locations

/ajax/get/division/list is confirmed JSON. Cascading district and upazila routes remain inferred.

Nested static pages

355 unique routes were recursively discovered: 69 roots, 171 children, and 115 grandchildren.

Widget parsing

Parse only the named widget container. The surrounding page shell repeats global links on every route.

Operational workflows

Use these sequences instead of treating object IDs as predictable or derivable.

  1. Discover: GET /views/sitemap, then parse SiteMapViewWidget.
  2. Filter: GET a collection with URL-encoded filters JSON and parse returned controls.
  3. Detail: follow the complete response-provided detail URL.
  4. Download: parse the file viewer for its complete object-storage URL.
  5. Recrawl: parse nested ContentViewerWidget links until no new route appears.

Point-in-time verification: 14 August 2026, Asia/Dhaka.
